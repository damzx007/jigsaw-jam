# Jigsaw Jam 🧩 — Atelier v2

เกมจิ๊กซอว์ออนไลน์ภาษาไทย สร้างห้อง ส่งลิงก์ และเล่นกับเพื่อนได้จากมือถือหรือคอม

## โหมดที่เล่นได้

- **Co-op 1–4 คน:** กระดานกลางร่วมกัน ความคืบหน้าซิงก์แบบเรียลไทม์ ต่อครบทุก 5 ชิ้นรับคำใบ้ทีม 1 ครั้ง (สะสมได้ 3 ครั้ง)
- **PvP 1v1:** คนละกระดาน ใช้ภาพและชิ้นชุดเดียวกัน ทั้งคู่ต้องกดพร้อมก่อนเริ่ม คนต่อครบก่อนชนะ
- **ไอเทม PvP เปิด/ปิดได้:** ต่อถูกได้ 1 พลัง (สะสมได้ 5) หมอกใช้ 3 พลัง บังภาพคู่แข่ง 6 วินาที โล่ใช้ 2 พลัง ป้องกัน 12 วินาทีและล้างหมอกได้ ไอเทมไม่รื้อชิ้นที่ต่อแล้ว
- รูปสำเร็จรูป 6 ภาพ (รวมสีพื้น กระเบื้องซ้ำ และลายทาง) และรูปอัปโหลดเอง ระบบครอปกลางภาพเป็น 4:3 และย่อก่อนส่ง
- ความยาก 12 / 24 / 48 / 108 / 192 / 300 ชิ้น รูปทรงเว้า/นูนที่เข้าคู่กัน
- เลือกชิ้นแล้วแตะช่อง หรือใช้ลากวาง รองรับคีย์บอร์ดด้วยปุ่ม Tab และ Enter
- ดูภาพตัวอย่าง สลับถาด จับเวลา และเล่นอีกรอบ
- เข้าห้องเดิมด้วยเบราว์เซอร์เดิมเพื่อคืนสถานะระหว่างเกม
- เมื่อกดออกจากห้อง โอนเจ้าของห้องให้คนถัดไป; PvP ที่กำลังเล่นจะให้ผู้เล่นที่เหลือชนะ

## รันในเครื่อง

ต้องใช้ Node.js 22 ขึ้นไป (แนะนำ 24)

```bash
npm ci
npm start
```

เปิด http://localhost:3000 แล้วให้เพื่อนเข้าผ่าน IP ภายในเครือข่ายเดียวกัน หรือ deploy เพื่อเล่นผ่านอินเทอร์เน็ต ใช้เบราว์เซอร์คนละโปรไฟล์/โหมดไม่ระบุตัวตนเพื่อทดสอบสองผู้เล่นบนเครื่องเดียวกัน เพราะตัวตนผูกกับคุกกี้ของเบราว์เซอร์

```bash
npm run check
npm test
```

ไม่ต้องใช้ฐานข้อมูล API key หรือไลบรารีภายนอก ใช้ Node HTTP, SSE และ Canvas

## Deploy บน Render

โครงการมี `render.yaml` สำหรับ **Web Service แบบ Free** แล้ว ต้องใช้ Web Service เพื่อรันห้องเกม ไม่ใช่ Static Site

1. สร้าง GitHub repository และ push โค้ดชุดนี้
2. เชื่อม GitHub กับ Render และสร้าง Blueprint จาก repository นี้ เพื่อใช้ `render.yaml`
3. หรือสร้าง Web Service โดยตั้ง Runtime = Node, Build = `npm ci`, Start = `npm start`, Health check = `/health`, Plan = Free
4. รอ deploy สำเร็จแล้วใช้ URL `.onrender.com` ของบริการสร้างห้องและชวนเพื่อน

Render กำหนด `PORT` ให้โดยอัตโนมัติ เซิร์ฟเวอร์ฟังที่ `0.0.0.0` และใช้ cookie แบบ Secure เมื่อ `NODE_ENV=production` ทุก API ใช้ origin เดียวกัน

ดูเอกสารผู้ให้บริการ: https://render.com/docs/deploy-node-express-app และ https://render.com/docs/free

## ข้อจำกัดของเวอร์ชันแรก

- ห้อง รูป และสถานะทั้งหมดเก็บในหน่วยความจำของ process เดียว **เมื่อบริการรีสตาร์ต deploy ใหม่ หรือ instance ถูกหยุด ห้องและความคืบหน้าจะหาย** ห้องที่ไม่มีการเชื่อมต่อหมดอายุหลังประมาณ 6 ชั่วโมง
- ใช้เซิร์ฟเวอร์เพียง 1 instance เท่านั้น ยังไม่รองรับ autoscaling หลาย instance
- Free instance ของ Render อาจพักเมื่อไม่ได้ใช้งาน การเปิดเกมครั้งแรกหลังพักอาจต้องรอ
- เป็นเกม casual สำหรับเล่นกับเพื่อน ยังไม่ใช่ระบบแข่งขันจัดอันดับหรือระบบป้องกันการโกงสมบูรณ์
- รหัสห้องเป็นลิงก์เชิญ ผู้ที่ทราบรหัสสามารถเข้าห้องที่ยังเปิดรับได้ จึงไม่ควรอัปโหลดภาพอ่อนไหว
- เข้าร่วมใหม่ได้ใน lobby เท่านั้น ถ้าหลุดระหว่างเล่นให้ใช้เบราว์เซอร์เดิมและรหัสเดิม; หากเจ้าของห้องปิดเบราว์เซอร์โดยไม่กดออก ต้องกลับมาเริ่ม/เล่นใหม่เอง
- Co-op ยังไม่มีถาดส่วนตัว ส่งชิ้น ปักหมุด เสียงสนทนา หรือย้ายกลุ่มชิ้น; เลือกชิ้นจากถาดร่วมและวางลงช่องที่ถูกต้อง

## โครงสร้าง

- `server.mjs` — HTTP server, ห้อง, session, SSE, กติกา และการตัดสินผลฝั่งเซิร์ฟเวอร์
- `public/app.js` — Canvas jigsaw, UI, การแตะ/ลาก และการเชื่อมต่อห้อง
- `public/style.css` — responsive layout
- `public/art/` — ภาพ SVG ที่สร้างสำหรับเกมนี้ ไม่มีการโหลดรูปจากเว็บอื่นขณะเล่น
- `test/multiplayer.test.mjs` — ทดสอบผู้เล่นหลาย session, การต่อซ้ำ, PvP, ไอเทม, SSE, validation และการออกจากห้อง
- `render.yaml` — การตั้งค่า deploy

## การตรวจสอบก่อนส่งมอบ

ผ่าน syntax checks และ automated integration tests 6 กรณี รวมการทดสอบจบเกมจริงแบบ Co-op 12 ชิ้นผ่านเบราว์เซอร์ ตรวจหน้าจอ desktop แล้ว ยังไม่ได้ทดสอบบนอุปกรณ์มือถือจริงหรือทดสอบโหลดจำนวนมาก

## เพิ่มใน v2

- ธีมสว่าง/มืด และเสียงเปิด/ปิด จำไว้เฉพาะอุปกรณ์นี้ ไม่เปลี่ยนหน้าจอเพื่อน
- โต๊ะไม้ ชิ้นมีขอบหนา เงา การยกชิ้นและเงาตอนลาก แสงและเสียงสังเคราะห์เมื่อต่อถูก กระดาษฉลองเมื่อจบเกม
- เอฟเฟกต์หมอกและขอบโล่ พร้อมเวลาคงเหลือ รองรับ prefers-reduced-motion
- เคอร์เซอร์/ชื่อเพื่อนและชื่อผู้ที่กำลังถือชิ้นผ่าน SSE event แยก ส่งพิกัดไม่เกินประมาณ 6 ครั้งต่อวินาที ไม่ส่งรูปซ้ำทุกครั้ง
- ภาพอัปโหลดส่งผ่าน endpoint ที่ตรวจสมาชิกห้อง โหลดครั้งเดียวต่อรอบ แทนฝัง base64 ในทุก state
- นับถอยหลัง 3–2–1 จากเวลาฝั่งเซิร์ฟเวอร์ ห้ามวางก่อนเริ่ม เลือกดูรูปได้ตลอด หรือเฉพาะนับถอยหลัง (แบบหลังปิดคำใบ้ภาพด้วย)
- ชิ้นสุ่มรหัสใหม่ทุกครั้งและสุ่มลำดับถาด หลีกเลี่ยงการเดาตำแหน่งจากเลขชื่อชิ้น
- ถาดแบ่งหน้า มือถือหน้าละ 12 ชิ้น จอใหญ่หน้าละ 48 ชิ้น และปุ่มขยายกระดานสูงสุด 300%
- ลำดับ revision ป้องกัน API response เก่าทับ state ใหม่ที่มาทาง SSE

การปิดภาพตัวอย่างเป็นกติกาสำหรับการเล่นปกติ ไม่ใช่การป้องกันผู้เปิด developer tools เพราะตัวเกมฝั่งเบราว์เซอร์ต้องมีภาพต้นฉบับเพื่อวาดชิ้นส่วน
