# Jigsaw Jam — Pocket & Parties v3

เกมจิ๊กซอว์ออนไลน์ภาษาไทย เล่นผ่านเบราว์เซอร์มือถือ iPad และคอม

**เล่น:** https://jigsaw-jam.onrender.com/

## สามโหมด

- **Co-op 1–8 คน:** ช่วยกันต่อกระดานเดียว สะสมคำใบ้ทีมทุก 5 ชิ้น
- **FFA 2–8 คน:** แต่ละคนมีสำเนากระดานของตัวเอง ภาพและรูปทรงเหมือนกัน ใครครบก่อนชนะ
- **Team 2–8 คน:** เลือกทีมดอกไม้หรือทีมใบไม้ สมาชิกทีมเดียวกันช่วยกันต่อกระดานร่วมของทีม คนละกระดานกับอีกทีม ทีมที่ครบก่อนชนะ

ก่อนเริ่ม FFA/Team ทุกคนต้องกดพร้อม โหมดทีมต้องมีสมาชิกทั้งสองทีม เปลี่ยนทีมใน lobby ได้และการเปลี่ยนทีมจะยกเลิกความพร้อมของทุกคน

## กระเป๋าไอเทม

ใช้ใน FFA/Team และเลือกปิดได้ตอนสร้างห้อง ไม่มีระบบพลังจากการต่อชิ้นแล้ว

- ตั้งกระเป๋า 3 / 4 / 5 ช่อง ค่าเริ่มต้น **4 ช่อง**
- ตั้งสุ่มทุก **5–120 วินาที** ค่าเริ่มต้น **20 วินาที** เริ่มนับหลัง 3–2–1 จบ
- ทุกคนสุ่มได้คนละ 1 ชิ้นในแต่ละรอบ กระเป๋าเต็มจะข้าม ไม่สะสมรางวัลค้างเกินช่อง
- ไอเทมแต่ละอันมี ID เฉพาะ ใช้ได้ครั้งเดียว เซิร์ฟเวอร์ตรวจความเป็นเจ้าของ เป้าหมาย และสถานะเกม
- **หมอก:** บังภาพเป้าหมาย 6 วินาที
- **โล่:** ป้องกันหมอก/สลับถาด 12 วินาที และล้างหมอกที่ติดอยู่
- **สลับถาด:** สลับเฉพาะชิ้นที่ยังไม่ต่อ ไม่รื้อชิ้นที่วางสำเร็จ
- FFA เลือกคู่แข่งจากเมนูเป้าหมาย ส่วน Team ใช้โจมตีทีมฝ่ายตรงข้ามและผลมีต่อสมาชิกทีมนั้น โล่ในโหมดทีมป้องกันทั้งทีม
- ใช้ไอเทมโจมตีผู้มีโล่อยู่จะถูกป้องกันและใช้ไอเทมนั้นไป ไม่มี friendly fire

## หน้าจอและการหยิบชิ้น

- ไม่มีเคอร์เซอร์หรือป้ายชื่อเพื่อนลอยทับกระดาน
- ชิ้นที่เพื่อนกำลังหยิบในถาดมี **กรอบสี** ตรงกับจุดสีในแถบผู้เล่นด้านบน แสดงเฉพาะผู้ที่ใช้กระดานร่วมกัน (Co-op หรือเพื่อนร่วมทีม)
- FFA ใช้คนละถาด จึงไม่ตีกรอบชิ้นจากการหยิบของฝ่ายตรงข้าม
- คอม: กระดานและถาดอยู่ข้างกัน กระเป๋าอยู่ใต้กระดาน ใช้ความสูง viewport โดยไม่เลื่อนทั้งหน้าเล่น
- มือถือ/iPad แนวตั้ง: ถาดย้ายลงล่างและแบ่งหน้าตามพื้นที่หน้าจอ
- จอเตี้ยแนวนอน: ย่อแถบควบคุมและวางถาดด้านข้าง
- ถ้าขยายกระดานเกิน 100% สามารถเลื่อนเฉพาะพื้นที่กระดานเพื่อเข้าถึงส่วนที่ซูมได้
- ธีมสว่าง/มืดและเสียงจำแยกในเครื่องนั้น ๆ รองรับ reduced motion

## ภาพและความยาก

รูปสำเร็จรูป 6 แบบ รวมภาพสีพื้น กระเบื้องซ้ำ และลายทาง หรืออัปโหลดรูปของตัวเอง (ครอปกลาง 4:3 และย่อก่อนส่ง)

จำนวนชิ้น: 12 / 24 / 48 / 108 / 192 / 300

เลือกดูภาพตัวอย่างระหว่างเกม หรือเฉพาะนับ 3–2–1 ก่อนเริ่ม แบบหลังปิดคำใบ้ภาพด้วย ตัวเลือกนี้เป็นกติกาเล่นปกติ ไม่ใช่ระบบป้องกันผู้ใช้ developer tools เพราะเบราว์เซอร์ต้องใช้ภาพต้นฉบับวาดชิ้นส่วน

## รันและตรวจสอบ

ต้องมี Node.js 22 ขึ้นไป (แนะนำ 24)

```bash
npm ci
npm start
```

เปิด http://localhost:3000

```bash
npm run check
npm test
```

ไม่ต้องใช้ API key ฐานข้อมูล หรือไลบรารี runtime เพิ่ม การซิงก์ใช้ HTTP + SSE การสุ่มไอเทมและกติกาอยู่ฝั่งเซิร์ฟเวอร์

## Deploy

ใช้ Render Web Service แบบ Free ที่ Singapore จาก branch `main`

- Build: `npm ci`
- Start: `npm start`
- `NODE_ENV=production`
- `NODE_VERSION=24.22.1`
- รับ `PORT` จาก Render และฟังที่ `0.0.0.0`

`render.yaml` เป็นตัวอย่างตั้งค่าสำหรับสร้างบริการใหม่ บริการปัจจุบันสร้างผ่าน Render โดยตรงและผูก main ให้ auto-deploy

## ข้อจำกัด

- ห้อง ภาพอัปโหลด และความคืบหน้าอยู่ในหน่วยความจำ เมื่อ deploy/restart/instance ถูกหยุด ห้องจะหาย
- ใช้ process/instance เดียว ยังไม่รองรับ autoscaling หลาย instance
- ห้องที่ไม่มีการเชื่อมต่อและไม่มีผู้ใช้ทำกิจกรรมเกิน 6 ชั่วโมงจะถูกลบ การสุ่มอัตโนมัติไม่ยืดอายุห้อง
- Free instance อาจพักเมื่อไม่ใช้งาน จึงอาจต้องรอเปิดครั้งแรก
- ใช้ browser profile เดิมเพื่อกลับเข้าห้องระหว่างเกม การปิดแท็บไม่ใช่การกดออกจากห้อง จึงเก็บตำแหน่งผู้เล่นไว้
- กดออกจากห้องจะโอนเจ้าของห้อง และตัดสินแพ้เมื่อเหลือผู้แข่งคนเดียว/เหลือทีมเดียวในโหมดแข่ง
- ผู้ที่รู้รหัสเข้าห้องได้ก่อนเริ่มเกม จึงไม่ควรอัปโหลดภาพอ่อนไหว
- เป็นเกม casual ไม่มีระบบจัดอันดับหรือป้องกันโกงสมบูรณ์

## ตรวจสอบ v3

ชุด integration tests ครอบคลุม Co-op/FFA/Team, 8 คน, การต่อร่วม/แยกกระดาน, bag capacity, timer, inventory ownership, friendly fire, shield/fog/shuffle/bomb, SSE และ lifecycle ห้อง

ตรวจเลย์เอาต์ผ่านเบราว์เซอร์ที่ viewport คอม 1366×768, มือถือ 375×812, iPad 768×1024 และแนวนอน 844×390 โดยตรวจทั้งภาพและ scroll dimensions ยังไม่ได้ทดสอบบนอุปกรณ์ iOS/iPadOS จริงหรือวัด FPS/โหลดผู้เล่นจำนวนมาก

### ระเบิดกระดาน (v3.1)
- สุ่มร่วมกับหมอก โล่ และสลับถาด โอกาสเท่ากัน
- ระเบิดชิ้นที่ต่อสำเร็จ 25% ปัดขึ้น สูงสุด 24 ชิ้น เลือกชิ้นใกล้จุดระเบิด กลับถาดให้ต่อใหม่
- FFA มีผลเฉพาะเป้าหมาย โหมดทีมทำลายกระดานร่วมเพียงครั้งเดียว พร้อมปรับยอดผลงานผู้เล่น
- โล่กันระเบิดได้ ไอเทมผู้โจมตียังถูกใช้ไป เอฟเฟกต์ขึ้นเฉพาะกระดานผู้รับ ไม่ขึ้นป้ายลอย
- เอฟเฟกต์ชิ้นกระเด็น คลื่นระเบิด แสง กระดานสั่น และเสียงสังเคราะห์ รองรับปิดเสียงและลดการเคลื่อนไหว
